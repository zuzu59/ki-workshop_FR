# Atelier – Jeudi 12/11/2026

« Travailler avec un agent de codage sur un appareil embarqué », 17h00–20h00.
Informations générales (matériel à prévoir, configuration, exercice) : [`README.md`](../README.md).

## Programme

| Horaire | Séquence |
| --- | --- |
| 17h00–17h15 | Accueil, introduction, présentations, démonstrations gPlug-Tapp |

| 17h30–17h45 | Configuration du notebook : dossier de l'atelier, image Docker, première réponse de l'agent |

| 18h00–18h10 | Déploiement du « starter » sur l'appareil |
| 18h10–18h20 | Démonstration de l'application de référence |
| 18h20–18h35 | Introduction à l'IA : contexte, bons et mauvais prompts, cycle de travail |
| 18h35–19h20 | Exercice avec l'agent |
| 19h20–19h50 | Présentation des résultats (15 min par groupe) : discussion, prompts utilisés, difficultés rencontrées, solutions efficaces |
| 19h50–20h00 | Clôture, retours (feedback) |

De 17h30 à 19h20, nous travaillerons en parallèle en deux groupes de 5 participants, chacun encadré par un coach.
