4 · Liaison avec l’appareil

Trois scripts communiquent avec le gPlug

L’IP figure dans le fichier .gplug :

echo <gplug-ip> > .gplug

ScriptActionExemple
upload.shTéléverser, vérifier la taille, recharger l’application./upload.sh app/spot.be
brcmd.shExécuter une expression Berry, réponse JSON./brcmd.sh 'tasmota.cmd("SpotStatus")'
log.shLire les dernières lignes de la console./log.sh

L’agent utilise uniquement ces scripts, pas de curl direct. brcmd.sh bloque les commandes de réinitialisation, de firmware et de Wi-Fi.

6 · Wi-Fi

Tous sur le même réseau

gPlug sur le Wi-Fi de l’atelier

  1. Brancher le gPlug, attendre 1–2 min.
  2. Se connecter à son Wi-Fi « gPlug… » ou « tasmota… », sinon ouvrir http://192.168.4.1.
  3. Choisir le Wi-Fi de l’atelier, mot de passe sur la fiche. Noter la nouvelle IP.
  4. Reconnecter l’ordinateur au Wi-Fi de l’atelier, ouvrir http://<gplug-ip>.

Sans IA

Éditeur de texte + navigateur · gratuit

  1. Modifier app/spot.be dans l’éditeur.
  2. WebUI : Outils → Gérer le système de fichiers → téléverser.
  3. Console : BrRestart, puis vérifier.

BRY: = message de Berry. « Berry initialized » et « Successfully loaded » sont normaux. BRY: avec erreur et numéro de ligne : consulter cette ligne dans spot.be.

ou ./upload.sh + ./log.sh

Avec IA

Docker + accès personnel · facturation par token

  1. Activer AI Tools, fixer un plafond de dépenses.
  2. Créer un token API, le définir avec le Product-ID comme variables.
  3. ./docker-run.sh, comme aujourd’hui.

Token API : ta clé, secrète comme un mot de passe. Tokens : fragments de texte (≈ ¾ de mot) lus et écrits par le modèle. Tu paies selon leur nombre.
